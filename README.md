# RSM-CRM

RSM Gayrimenkul için Cloudflare Workers + D1 tabanlı internet CRM.

## Mevcut modüller
- Ana Panel
- Müşteriler
- Mülk Sahipleri
- Portföyler
- Talepler
- Takipler
- Müşteri–portföy eşleştirme

## Cloudflare
Worker adı: `rsm-gayrimenkul-crm`
D1 binding adı: `DB`
D1 database: `rsm-crm-db`

`worker.js` üretim Worker kodudur.
